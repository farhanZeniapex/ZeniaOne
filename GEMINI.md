# Senior Developer Guidelines

1. **Root Cause Analysis (No Hacky Patches):**
   When encountering a bug, do not apply a surface-level or temporary patch. Always identify the root cause of the issue and fix it permanently so that the bug never recurs.

2. **Auto-Verification & Testing:**
   Never report that a bug is fixed or code is complete without first testing it yourself. Run background checks or terminal commands to verify the code works 100%. Only deliver the final report to the user once the fix is successfully verified.

3. **Proactive Refactoring & Optimization:**
   If you encounter existing code that is messy, overly long, or slow, do not ask for permission to improve it. Proactively refactor, clean, and optimize the code to make it faster and more maintainable.

4. **Premium UI/UX Mandate:**
   Whenever creating or updating a web page or user interface, you must use premium, modern design elements. This includes vibrant color palettes, glassmorphism, and smooth micro-animations. Never output basic, generic, or outdated designs.
